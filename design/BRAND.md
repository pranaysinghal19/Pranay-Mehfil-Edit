# Mehfil Brand & UI System

## Core mark
Use the approved overlapping-arches Mehfil mark. Do not casually redraw it. Use the production SVG master when committed.

Concept: **Two paths. One space.**

## Palette
- Ink: #16181D
- Bone: #F6F2EA
- Coral: #FF5C4D
- Indigo: #4937A8

## Product feel
Bold, urban, editorial, culturally current, youthful and premium without becoming a luxury-club cliché.

Avoid neon-glow overload, hearts/dating clichés, swipe-card language for people, excessive pills, profile-avatar clutter, ornate luxury serif UI and generic SaaS-dashboard blue.

## Consumer app
Bottom nav: Home · Events · Live · Membership · Me

Home is **My Social Life**, not a catalogue.

Event screens use large editorial photography, strong event identity, clear city/venue/time and reassuring solo-attendance language.

Live transforms toward Ink/dark treatment. Coral indicates action.

Profile identity matters: user can view, edit and preview their own Mehfil Card.

## Ops
Ops is denser but still recognizably Mehfil.

Direction:
- Ink sidebar
- Bone workspace
- Coral for urgent/action states
- Indigo for secondary system state
- strong numeric event-status cards
- clear safety severity hierarchy

Pages:
Dashboard · Events · Check-in · Live · Safety · Staff · Attendees · Membership · Finance · Feedback/Research · Analytics · Audit · Settings
