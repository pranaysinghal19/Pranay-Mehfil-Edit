# Mehfil Product Non-Negotiables

Mehfil is an offline-first events/community platform. The app supports city discovery, anticipation, attendance, real-world encounters, mutual connection and continuity after the event. It is not a profile-shopping dating product.

## Consumer navigation
Home · Events · Live · Membership · Me

## My Mehfil Card
2–3 photos, first name, age, city, gender, 3–6 interests, optional short line, edit profile and a preview of what another attendee sees after a QR scan. Profiles are not publicly searchable.

## Event formats
Mehfil Social · Mehfil Singles · Mehfil Table · Mehfil Sundays · Mehfil After Dark

## Tickets
Prototype examples: ₹449 Entry; ₹499 Entry + 1 Drink Token. The ₹50 difference is not described as an alcohol charge; the beverage token is generic.

## Membership
One membership: ₹899/month. Includes one eligible event per billing month, one drink token, priority booking, member pricing and eligibility for selected member/invite-only experiences. Invite-only access does not consume the monthly event credit.

## Live
Live is always visible in bottom navigation. Correct six-digit event code alone never grants access; ticket, check-in, Live state, account status and server authorization also apply.

Active interface stays small: Show my QR · Scan someone · Connections · Need help? · Event info.

## Event team
HOST: guest-facing social energy, introductions, activities and Live explanation.
VOLUNTEER: check-in, queues, ticket scans and assistance.
MARSHAL: safety/conduct, reports, interventions and incidents.
EVENT_LEAD: setup, staffing, venue, Live controls, removals and operational resolution.

Private connection content is not exposed to staff by default.
